REYSEC — VERSIÓN PARA GITHUB PAGES

El archivo principal es index.html. Mantén la carpeta assets junto a index.html para que carguen el logo y las fotografías.

Para subirlo:
1. Carga index.html y la carpeta assets a la raíz del repositorio de GitHub.
2. En GitHub, abre Settings > Pages.
3. En Build and deployment, elige Deploy from a branch, selecciona la rama principal y la carpeta /(root), y guarda.

Las fotografías son ilustrativas y generadas para la página.
